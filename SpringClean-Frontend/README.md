# SpringClean-Frontend
# Features:
- Users are able to create companies
- Become Cleaners in that company
- Can book from that companys

# Technologies Used:
- HTML/CSS/JavaScript
- ReactJs
- SpringBoot

# Installations:
Clone the repository
git clone https://github.com/your-username/your-repo.git

# Navigate into the project folder
cd SpringClean-Frontend

# Install dependencies
npm install

# How to run:
npm start / npm run dev
